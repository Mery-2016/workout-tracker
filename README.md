# Workout Tracker

Локальное приложение для учёта тренировок. Сайт на React, сервер на Node.js, данные — в файле SQLite на вашем компьютере. Вход не нужен: это программа для одного человека.

Интерфейс на русском и узбекском. Есть светлая и тёмная тема. Язык и тема запоминаются в браузере. Сами тренировки в браузере не хранятся.

## Что нужно заранее

- [Node.js](https://nodejs.org) версии 20 или новее. Проверка: `node -v`
- npm, он ставится вместе с Node.js. Проверка: `npm -v`

## Установка

Откройте терминал в папке проекта и выполните:

```bash
npm install
```

Команда скачает библиотеки и для сайта, и для сервера.

Если установка останавливается с текстом `unable to verify the first certificate`, в том же окне PowerShell выполните и повторите установку:

```powershell
$env:NODE_OPTIONS = "--use-system-ca"
npm install
```

## Запуск

```bash
npm run dev
```

Откроются два процесса:

- сервер API: http://localhost:3001
- сайт: http://localhost:5173

В браузере открывайте **http://localhost:5173**. Сайт сам обращается к серверу.

Остановка: в том же терминале нажмите `Ctrl+C`.

При первом запуске сервер создаст файл базы:

`backend/data/workouts.db`

После перезапуска тренировки остаются в этом файле. Не удаляйте его, если хотите сохранить историю.

## Как проверить, что всё работает

1. Откройте сайт и нажмите «Добавить тренировку».
2. Введите название, дату и длительность. При желании добавьте упражнение и подходы.
3. Нажмите «Сохранить тренировку».
4. Откройте «Обзор» и «Статистика» — цифры и графики берутся из базы, а не из примеров.
5. На странице «Настройки» статус сервера должен быть успешным.
6. Остановите `npm run dev` и запустите снова. Тренировка должна остаться.

Проверка только сервера: http://localhost:3001/api/health  
Ответ выглядит так: `{"ok":true,"database":"ok","foreign_keys":true}`

## Другие команды

```bash
npm test
npm run typecheck
npm run build
```

- `npm test` — проверки API и расчётов объёма.
- `npm run typecheck` — проверка TypeScript.
- `npm run build` — сборка сервера в `backend/dist` и сайта в `frontend/dist`.

Запуск уже собранного сервера:

```bash
npm start
```

Собранный сайт сам по себе API не включает. Для обычной работы используйте `npm run dev`.

## Страницы

- Обзор — тренировки за неделю и месяц, общее время, объём, дистанция, последние записи, графики за 7 и 30 дней.
- Все тренировки — поиск, фильтр по типу и датам, сортировка, страницы, просмотр, правка, удаление.
- Форма — тренировка и несколько упражнений с подходами.
- Карточка тренировки — подробности, правка и удаление с подтверждением.
- Статистика — периоды 7, 30, 90 дней и всё время, дни недели, частые упражнения, динамика веса.
- Настройки — описание, единицы (кг, км, минуты), язык и тема, проверка сервера.

## Как считаются цифры

- Число тренировок — сколько записей попало в период.
- Время — сумма минут.
- Объём — сумма «вес × повторения» только у подходов, где вес указан. Пустой вес в сумму не входит.
- Дистанция — сумма только тех километров, которые вы ввели.
- Если данных нет, на экране нули и пустое состояние.

Неделя считается с понедельника по воскресенье. Дата тренировки хранится как `ГГГГ-ММ-ДД` без сдвига часового пояса.

## Папки

- `frontend` — страницы, компоненты, переводы, запросы к API.
- `backend/src` — сервер, таблицы SQLite, проверки данных, статистика.
- `backend/tests` — автоматические проверки.
- `backend/data` — файл базы. Он не попадает в git.

## API

- `GET /api/health`
- `GET /api/workouts` — параметры `search`, `type`, `from`, `to`, `sort`, `page`, `limit`
- `GET /api/workouts/:id`
- `POST /api/workouts`
- `PUT /api/workouts/:id`
- `DELETE /api/workouts/:id`
- `GET /api/stats/summary?period=7d|30d|90d|all`
- `GET /api/stats/activity?period=7d|30d|90d|all`
- `GET /api/stats/exercises?period=30d&exercise=Присед`

Создание и изменение тренировки вместе с упражнениями выполняется одной транзакцией: либо сохраняется всё, либо ничего.
