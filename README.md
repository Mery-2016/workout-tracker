# Workout Tracker

Сайт для учёта тренировок. Страницы на React, сервер на Node.js, тренировки лежат в облачной базе [Neon](https://neon.tech). У каждого человека свой аккаунт: чужие тренировки не видны.

Интерфейс на русском и узбекском. Есть светлая и тёмная тема. Язык и тема запоминаются в браузере.

Готовый сайт выкладывается на [Vercel](https://vercel.com). Адрес вида `https://....vercel.app` открывает само приложение: вход, регистрацию и таблицу тренировок.

Страница `https://mery-2016.github.io/workout-tracker/` — это только текст инструкции. Там программа не запускается.

## Что сделать вам: база Neon

1. Откройте https://neon.tech и нажмите **Sign up**. Удобно войти через GitHub.
2. Нажмите **New project**. Имя можно оставить любым, например `workout-tracker`. Регион выберите ближайший. Нажмите **Create**.
3. На странице проекта нажмите **Connect**.
4. Скопируйте строку, в которой есть слово **pooled** (в адресе есть `-pooler`). Она начинается с `postgresql://`. Это адрес базы. Никому его не отправляйте.
5. Придумайте длинную секретную фразу из 20 или больше символов. Она нужна, чтобы подделывать вход было трудно. Запишите её себе. Пример вида: `moy-sekret-2026-workout-tracker`.

## Что сделать вам: сайт на Vercel

Код уже лежит на GitHub: https://github.com/Mery-2016/workout-tracker

1. Откройте https://vercel.com и нажмите **Sign up**. Войдите через GitHub тем же аккаунтом, где лежит проект.
2. Нажмите **Add New…** → **Project**.
3. Найдите репозиторий `workout-tracker` и нажмите **Import**.
4. Поле **Root Directory** оставьте пустым. Не выбирайте папку `frontend`.
5. Если Vercel спрашивает настройки сборки, проверьте:
   - Build Command: `npm run build -w frontend`
   - Output Directory: `frontend/dist`
6. Раскройте **Environment Variables** и добавьте две строки:
   - имя `DATABASE_URL`, значение — скопированный адрес Neon
   - имя `AUTH_SECRET`, значение — ваша секретная фраза
7. Нажмите **Deploy** и подождите, пока сборка станет зелёной.
8. Откройте адрес, который покажет Vercel. Нажмите «Зарегистрируйтесь», введите имя, почту и пароль от 8 символов. После этого откроется таблица и обзор. Тренировки этого аккаунта сохраняются в Neon.

Если страница не открывается, подождите минуту и обновите её. Если на сайте написано «Ошибка сервера», откройте проект на Vercel → **Settings** → **Environment Variables** и проверьте, что обе строки сохранены, затем **Deployments** → три точки у последней сборки → **Redeploy**.

## Как запустить у себя на компьютере

Нужен [Node.js](https://nodejs.org) версии 20 или новее.

1. В папке `backend` создайте файл `.env` (рядом с `package.json` сервера). Скопируйте в него текст из `.env.example`.
2. Вставьте свой `DATABASE_URL` и свою фразу `AUTH_SECRET`. Это могут быть те же значения, что на Vercel.
3. В корне проекта выполните:

```powershell
$env:NODE_OPTIONS = "--use-system-ca"
npm install
npm run dev
```

4. Откройте http://localhost:5173 и зарегистрируйтесь.

Остановка: `Ctrl+C`.

Если `npm install` пишет `unable to verify the first certificate`, команда с `NODE_OPTIONS` выше как раз для этого случая. Выполните её в том же окне PowerShell и снова `npm install`.

Старые тренировки из файла `backend/data/workouts.db` в Neon сами не переносятся. Это была отдельная база без аккаунтов.

## Как считаются цифры

- Число тренировок — сколько записей попало в период.
- Время — сумма минут.
- Объём — сумма «вес × повторения» только у подходов, где вес указан.
- Дистанция — сумма только тех километров, которые вы ввели.
- Если данных нет, на экране нули и пустое состояние.

Неделя считается с понедельника по воскресенье. Дата тренировки хранится как `ГГГГ-ММ-ДД` без сдвига часового пояса.

Создание и изменение тренировки вместе с упражнениями выполняется одной транзакцией: либо сохраняется всё, либо ничего.
